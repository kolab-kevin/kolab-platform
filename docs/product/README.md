# Product

KŌLAB Platform is the unified foundation for Kolab's product ecosystem — not a single-product app.

## Business verticals

1. **Kolab Agency** — talent and brand management
2. **TikTok Creator Management** — creator roster, campaigns, analytics
3. **TikTok Shop** — commerce, payouts, inventory integrations
4. **AI Services** — content generation, moderation assist, insights
5. **Live Streaming** — stream management and audience tools
6. **SYMLCAST** — future broadcast integration

## Application mapping

| Audience | Application |
|----------|-------------|
| Public / brands | web |
| Internal ops | admin |
| Creators | creator-portal |
| Trust & safety | moderator |
| Mobile clients | mobile-api |
| Third-party integrations | public-api |
